# ECHO Project Page

Project page for ECHO: Edge-Cloud Humanoid Orchestration for Language-to-Motion Control.

- **Paper**: https://arxiv.org/pdf/2603.16188
- **Code**: https://github.com/Hxxxz0/ECHO_CODE
- **Weights**: https://modelscope.cn/models/Hzzzz001/ECHO/summary

## Structure

- `index.html` — main project page
- `static/` — images, videos, CSS, JS
- `sim/`, `sim-preview/` — simulation demo videos
- `real/`, `real-preview/` — real robot demo videos

## Deploy

Push to `main` branch, Vercel auto-deploys to https://echo-phi-eight.vercel.app.
